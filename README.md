# Описание
car market analyzer - проект для предсказания цены автомобиля по входным данным(бренд, модель, год выпуска, пробег, объем двигателя, тип КПП, тип топлива, город продажи).

Предсказание осуществляется путем передачи данных модели линейной регрессии через API в json формате.

Проект обладает валидацией загружаемого датасета при помощи pandas в формате csv файла, но имеет эталонные файлы того же формата для правил валидации.

Также имеются расчет статистики и визуализация данных(не включена в API).

Для проверки работоспособности валидации датасета и API используется pytest.

## Технологии
Технологии используемые в проекте включают в себя python,pandas,scikit-learn,FastAPI,pytest,Docker.

## Возможности
Валидация датасета представляет собой очистку данных csv файла: исправление типов данных, обработка пропусков, недопустимых значений и комбинаций, удаление дубликатов.

В расчет статистики входят: общая статистика(кол-во авто, их минимальная, максимальная, средняя, медианная цены, средний пробег, средний год выпуска),
общая статистика по бренду,средняя цена по каждому году выпуска(не включена в API),кол-во авто в диапазонах пробега, кол-во авто по выбранному признаку(не включена в API).

Визуализация включает: визуализация динамики изменения цены в зависимости от года выпуска, кол-во авто в интервалах пробега, общей статистики по брендам, 
статистика по кол-ву авто каждого типа топлива,кол-ву авто каждого типа КПП,кол-ву авто в каждом городе.

Тестирование представляет собой проверку валидации датасета путем подачи неправильных данных, их преобразования и сравнения с ожидаемыми на выходе данными.

Тестирование API включает проверку валидации входных данных, HTTP-статусов и ответов на запросы.

Тестирование выполняется при помощи pytest.

## Машинное обучение
Обучение и сохранение модели линейной регрессии реализуется при помощи scikit-learn.

Выбор именно модели линейной регрессии обусловлен тестированием как этой модели, так и модель случайного леса для регрессии.

## Ограничения
Небольшой размер обучающего датасета ограничивает обобщающую способность модели, если входные данные выходят за диапазон обучающих параметров. В датасете год выпуска ограничен: в нем авто с годом выпуска от 2008 до 2022.
В связи с этим в API ограничен ввод года выпуска ниже 2008, а прогнозы для авто с годом выпуска больше 2022 являются экстраполяцией.

## Запуск
Для запуска проекта необходимо клонировать репозиторий и перейти в корневую директорию проекта, затем собрать Docker-образ и запустить контейнер:
```bash
docker build -t car-market-api .
docker run --rm -p 8080:8000 car-market-api
```
Сборка и запуск выполняются из корня проекта с запущенным Docker Engine.
После этого по адресу http://localhost:8080/docs будет доступен Swagger UI, в котором можно будет отправить запросы.

## API
Для получения статистки и вывода авто по характеристикам используются get запросы: /cars выводит все авто. Данный запрос обладает 4 необязательным параметрами(brand,fuel,year_min,year_max).
Поддерживается как полное отсутствие параметров так и наличие всех 4 одновременно. При указании параметра brand выведутся авто только этого бренда.
При указании параметра fuel выведутся авто только с этим типом топлива.
При указании параметра year_min выведутся авто с годом выпуска не ниже указанного.При указании параметра year_max выведутся авто с годом выпуска не выше указанного.

Get запрос /stats выведет общую статистику. Запрос /stats/brands выведет общую статистику брендов.
Запрос /stats/brands/brand выводит статистику по конкретному бренду, указать название бренда нужно вместо brand.

Для получения предсказания используется post запрос /predict. Тело запроса предоставляется в json формате. Внутри тела необходимо указать характеристики авто, по которому нужно получить предсказание.
Например :
 ```json
{
  "brand": "Ford",
  "model": "Focus",
  "year": 2008,
  "mileage_km": 137000,
  "engine_l": 1.6,
  "fuel": "petrol",
  "transmission": "manual",
  "city": "Moscow"
}
```

Пример ответа:
```json
{
  "predicted_price": 188249.7299735091
}
```
